## Projetos

- **[WasTech](https://github.com/Aderlangio123/wast-tech-completa)**: plataforma de tecnologia e sustentabilidade para a agricultura, feita em equipe. Usa Node.js, React, Firebase e dados climáticos da NASA POWER. Rendeu Menção Honrosa no Desafio dos Dados 2025 (entre mais de 340 equipes) e Bronze na OBT.
- **[API de Seleções](https://github.com/Aderlangio123/api-selecoes-nodejs)**: CRUD de seleções de futebol com Node.js, Express e MySQL. [Ver API no ar](https://api-selecoes-nodejs.onrender.com/selecoes).
- **[FocusFlow](https://github.com/Aderlangio123/FocusFlow-Tarefas)**: gerenciador de tarefas em React e TypeScript, com filtros e dados salvos no LocalStorage. [Ver demo](https://focus-flow-tarefas.vercel.app).
- **[Galeria de Jogos](https://github.com/emanuel378/BibliotecaGames)**: feita em dupla com o Emanuel, consome a API FreeToGame. [Ver demo](https://biblioteca-games-nfcz.vercel.app).
